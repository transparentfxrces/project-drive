# Project Drive 🏈

## Mission

Project Drive is a mobile app that helps high school football players track training, recovery, practices, and performance while making improvement fun, measurable, and motivating.

## Why I'm Building It

I noticed that players often track workouts in different places—or not at all. I want to create one app that helps athletes improve consistently while giving coaches meaningful insights into player development.
